對標站怎麼做(renata-hair.com.tw)

對標站:官網首頁 · 部落格列表
可以借的做法
  • 首頁第一屏放品牌數據(40 年、10000 家沙龍指定、100000 設計師合作),先建立信任再談產品。看範例
  • 產品用三種入口分類:依需求、依品項、依系列。沙龍找貨的人用需求找,熟客用系列找。看範例
  • 部落格分四類:動態資訊、課程資訊、保養知識、人物專欄。人物專欄是沙龍主理人訪談,這是 B2B 站最有說服力的內容。看範例
  • 首頁「線上頭皮/髮絲諮詢」區塊,把專業服務做成入口。看範例
  • 兩組 LINE 帳號分流:一般消費者一組、沙龍設計師一組,按鈕上直接標明。看範例
  • 集團實力區塊:工廠生產、檢驗檢測、研發調配,一站式實力。看範例
不照抄的地方
  • 對標站是零售導向,導覽列有本月活動、熱銷、新品、購物金跑馬燈。Helen Seward 定位是 B2B 形象站,這些不放。
  • 對標站的「品牌故事」「歷史沿革」「沙龍職業產品」三頁實際上是空白或只有圖片,全站也沒有任何表單,合作只留一個 email。這正是 Helen Seward 可以做得更好的地方。

五

形象站與購物功能怎麼處理

ShopLine 官方文件沒有「型錄模式」或「全站隱藏售價與購物車按鈕」的設定。目前查到的做法:

做法效果限制
產品系列頁改成介紹頁,不放商品格訪客在系列頁看不到售價與購物車商品單頁仍會顯示售價與加入購物車
商品單頁不放進導覽列與任何頁面連結一般訪客走不到商品單頁搜尋引擎仍可能收錄舊商品頁網址
商品逐一設為「隱藏」商品單頁與搜尋都不出現現有 127 筆商品要逐筆處理;隱藏後現有給特定客戶的下單方式需另外安排
頁首購物車圖示無法從設定關閉可用自訂 CSS 隱藏,需實測

建議:先做前兩項(系列頁改介紹頁、不連結商品單頁),頁首購物車圖示用自訂 CSS 隱藏並實測。商品是否全部隱藏,依業主現行「主動聯繫的消費者才提供下單方式」的做法決定。

另外三個「活動尚未開始」的促銷頁,改版時關閉或移除,避免訪客點進去看到空頁。
